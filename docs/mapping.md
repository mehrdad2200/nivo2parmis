# راهنمای فایل نگاشت (`mapping.json`)

فایل را با `nivo2parmis init-mapping` بسازید و ویرایش کنید.

```json
{
  "version": 1,
  "cash_account": 152,
  "banks": { "بانک ملت": 176 },
  "categories": [
    { "group": "expense", "parent": "", "name": "حمل و نقل", "count": 1705, "sum": 51000000,
      "target": { "under": 16, "title": "حمل و نقل" } },
    { "group": "expense", "parent": "خانواده", "name": "ساختمان",
      "target": { "existing": 193 } }
  ]
}
```

## `cash_account`
شناسه‌ی حساب نقد پارمیس (زیر «صندوق‌ها»). شناسه‌ها را در خروجی `inspect` ببینید.

## `banks`
نام بانک در نیوو ← شناسه‌ی حساب بانکی در پارمیس (زیر «بانک‌ها»). همه‌ی بانک‌هایی که تراکنش دارند باید نگاشت شوند.

## `categories`
هر ورودی یک دسته‌ی نیوو را با `group` (`income` یا `expense`)، `parent` (والد؛ خالی برای دسته‌ی اصلی) و `name` مشخص می‌کند
و `target` می‌گوید به کدام حساب پارمیس برود. `count`/`sum`/`note` فقط اطلاعاتی‌اند. سه نوع هدف:

| هدف | معنی |
|---|---|
| `{"existing": 208}` | حساب موجود با این شناسه. باید حساب پایانی باشد |
| `{"under": 16, "title": "مسافرت"}` | حساب پایانی «مسافرت» زیر حساب ۱۶ (ریشه یا زیرگروه). اگر وجود داشت همان، وگرنه ساخته می‌شود |
| `{"under_new_sub": {"root": 1, "title": "X"}, "title": "Y"}` | زیرگروه «X» زیر هزینه‌ها (۱) یا درآمدها (۲) (اگر هم‌نامش بود همان) و حساب پایانی «Y» داخلش |

دسته‌ای که در فایل نباشد با همان قاعده‌ی خودکار نگاشت می‌شود.

## قاعده‌ی خودکار
1. نام دسته (با نرمال‌سازی ی/ک و نیم‌فاصله) با **یک** حساب پایانی هم‌نام زیر هزینه‌ها/درآمدها برابر است ← همان حساب.
2. دسته‌ی اصلی که زیردسته دارد ← زیرگروه هم‌نام (موجود یا جدید) و تراکنش‌های مستقیمش در حساب `«نام (عمومی)»`.
3. زیردسته ← حساب پایانی زیر زیرگروه والد. اگر والدش با یک حساب پایانی موجود یکی شده باشد، زیردسته هم‌ردیف آن با عنوان `«والد - فرزند»` ساخته می‌شود.
4. بقیه ← حساب پایانی مستقیم زیر ریشه.

اگر چند حساب هم‌نام باشند (مبهم)، حدس زده نمی‌شود و حساب جدید ساخته می‌شود؛ می‌توانید دستی `existing` بدهید.

## نکته: ادغام معنایی
مثلاً «غذا و نوشیدنی» نیوو را می‌شود به زیرگروه «اغذیه» پارمیس بست:
```json
{ "group": "expense", "parent": "", "name": "غذا و نوشیدنی", "target": { "under": 12, "title": "غذا و نوشیدنی" } }
```
(۱۲ شناسه‌ی «اغذیه» در درخت پیش‌فرض است؛ در `inspect` یا خود پارمیس ببینید.)
