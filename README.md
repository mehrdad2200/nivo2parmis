# nivo2parmis

ابزار متن‌باز برای **انتقال و ادغام پشتیبان برنامه‌ی «نیوو» (Nivo) در پشتیبان برنامه‌ی «پارمیس» (Parmis)**.

> اگر سال‌ها با نیوو حسابداری شخصی نوشته‌اید، بعد نیوو به‌روزرسانی نشد و به پارمیس رفتید، این ابزار تمام تاریخچه‌ی نیوو را
> به‌شکل اسناد واقعی پارمیس درمی‌آورد و با پشتیبان فعلی پارمیس‌تان ادغام می‌کند. خروجی یک فایل `.par` است که در پارمیس
> «بازیابی» می‌کنید و همه‌چیز کنار هم است.

*English summary: a CLI that decrypts a Nivo (Persian personal-finance Android app) `.nivo` backup and merges its history
into a Parmis `.par` backup as native Parmis ledger entries, with a reviewable category mapping and built-in verification.*

---

## ⚠️ قبل از هر کاری

* این پروژه **غیررسمی** است و ربطی به سازندگان نیوو یا پارمیس ندارد.
* فایل پارمیس ورودی هرگز تغییر نمی‌کند؛ خروجی یک **فایل جدید** است. با این حال **پیش از بازیابی، از پارمیس فعلی خود پشتیبان بگیرید.**
* ابزار فقط برای باز کردن **پشتیبان‌های خودتان** است.
* فایل‌های `.nivo` و `.par` اطلاعات مالی شخصی‌اند؛ هرگز آن‌ها را در گیت‌هاب یا Issue نگذارید (`.gitignore` این مخزن جلوی آن را می‌گیرد).

## نصب

پایتون ۳٫۹ یا بالاتر لازم است.

```bash
git clone https://github.com/<your-name>/nivo2parmis.git
cd nivo2parmis
pip install .
```

## ساده‌ترین راه (بدون ترمینال)

1. **پایتون** را از [python.org](https://www.python.org/downloads/) نصب کنید (در ویندوز تیک **Add Python to PATH** را بزنید).
2. زیپ را Extract کنید و دو فایل پشتیبان‌تان (`.nivo` و آخرین `.par` پارمیس) را **داخل همان پوشه** بگذارید.
3. روی **`Start.bat`** دوبار کلیک کنید (مک: `Start.command`، لینوکس: `start.sh`).
   بار اول چند بسته‌ی لازم را خودش نصب می‌کند (نیاز به اینترنت).
4. در پنجره‌ای که باز می‌شود فایل‌ها خودکار پیدا شده‌اند (یا با «انتخاب…» خودتان انتخاب کنید) ← **«ادغام کن»**.

فایل جدید `parmis-merged.par` کنار فایل پارمیس ساخته می‌شود و یک پیام خلاصه (از جمله تغییر موجودی‌ها) می‌بینید.
فایل اصلی شما هرگز تغییر نمی‌کند و فایل قبلی هم هیچ‌وقت رونویسی نمی‌شود.

> **بدون نصب پایتون:** در تب **Releases** مخزن (پس از اجرای workflow ‏`build-exe`) یک فایل `Nivo2Parmis.exe` برای ویندوز هست؛ فقط دوبار کلیک کنید.
> پنجره از نگاشت **خودکار** استفاده می‌کند. برای کنترل کامل دسته‌ها از روش خط فرمان پایین استفاده کنید.

## استفاده‌ی پیشرفته با خط فرمان (۴ قدم)

فرض کنید `my.nivo` پشتیبان نیوو و `parmis-latest.par` آخرین پشتیبان پارمیس شماست.

**۱) ببینید توی فایل نیوو چیست**

```bash
nivo2parmis inspect --nivo my.nivo --parmis parmis-latest.par
```

تعداد تراکنش‌ها، بازه‌ی تاریخ، دسته‌ها، بانک‌ها و حساب‌های نقد/بانکی پارمیس را نشان می‌دهد.

**۲) فایل نگاشت بسازید و بازبینی کنید**

```bash
nivo2parmis init-mapping --nivo my.nivo --parmis parmis-latest.par -o mapping.json
```

برای هر دسته‌ی نیوو یک پیشنهاد خودکار ساخته می‌شود: اگر در پارمیس حسابی با همان نام باشد از همان استفاده می‌شود، وگرنه حساب
جدید ساخته می‌شود. فایل را باز کنید و هر جا خواستید تغییر دهید (راهنما: [docs/mapping.md](docs/mapping.md)).
همین‌جا مشخص کنید کدام حساب پارمیس «کیف پول» (`cash_account`) و کدام حساب‌ها بانک‌های شما هستند (`banks`).

**۳) اجرای آزمایشی** (چیزی نوشته نمی‌شود)

```bash
nivo2parmis merge --nivo my.nivo --parmis parmis-latest.par -o out.par --mapping mapping.json --dry-run
```

**۴) ادغام نهایی**

```bash
nivo2parmis merge --nivo my.nivo --parmis parmis-latest.par -o parmis-merged.par --mapping mapping.json --report report.json
```

سپس `parmis-merged.par` را در پارمیس بازیابی کنید (از بخش پشتیبان‌گیری و بازیابی خود برنامه).

> بدون `--mapping` هم کار می‌کند (نگاشت خودکار)، فقط اگر حساب نقد یا بانک را نتواند حدس بزند خطا می‌دهد و راهنمایی می‌کند.

  ✔ integrity_check
  ✔ ساختار دیتابیس بدون تغییر
  ✔ همه‌ی اسناد قبلی پارمیس بدون تغییرند — 3 سند
  ✔ هر تراکنش نیوو دقیقاً یک‌بار (تاریخ/مبلغ/یادداشت/جهت) — 84 ردیف

برای امتحان بدون داده‌ی شخصی، پوشه‌ی [`examples/`](examples/) یک پشتیبان ساختگی نیوو و پارمیس دارد:

```bash
nivo2parmis merge --nivo examples/sample_nivo.nivo --parmis examples/sample_parmis.par -o /tmp/out.par
```

## ابزار چه می‌کند؟

| در نیوو | در پارمیس |
|---|---|
| هر تراکنش (یک دسته + مبلغ مثبت/منفی) | یک سند «دریافت» (درآمد) یا «پرداخت» (هزینه) بین حساب کیف پول/بانک و حساب دسته |
| جفت تراکنش «جیب به جیب» | یک سند «انتقال» |
| اختلاف دو سمت یک انتقال | یک سند اصلاحی جدا با توضیح (تا موجودی‌ها دقیق بماند) |
| دسته و زیردسته | حساب پایانی در درخت هزینه‌ها/درآمدها (حساب موجود هم‌نام، وگرنه حساب جدید) |
| پروژه | برچسب از نوع «پروژه» |
| یادداشت، تاریخ شمسی، ساعت | همان‌ها (ساعت از زمان ثبت، به وقت تهران) |

اسناد قدیمی بعد از آخرین شماره‌ی سند پارمیس اضافه می‌شوند (نه جایگزین)، و تاریخ شروع سال مالی به اولین تاریخ نیوو
برمی‌گردد تا گزارش‌های پارمیس همه‌چیز را ببینند.

### اعتبارسنجی خودکار

بعد از هر ادغام این موارد بررسی می‌شود و اگر یکی نخواند، **فایل خروجی حذف می‌شود**: سلامت دیتابیس، یکسان بودن ساختار،
دست‌نخورده بودن همه‌ی اسناد و حساب‌های قبلی پارمیس، وجود دقیقاً یک‌باره‌ی هر تراکنش نیوو (تاریخ/مبلغ/یادداشت/جهت)،
درستی مسیر حساب هر سند، و برابری اثر خالص با نیوو.

## نکات مهم

* **موجودی‌ها تغییر می‌کند.** پارمیس معمولاً از صفر شروع شده؛ پس از ادغام، جمع گردش نیوو به موجودی کیف پول/بانک اضافه می‌شود. جزئیات و راه‌حل: [docs/faq.md](docs/faq.md).
* **شماره‌ی سند** اسناد قدیمی بعد از اسناد فعلی است (ولی به ترتیب زمان). این کار عمداً انجام می‌شود تا ارجاع‌های داخلی پارمیس (اقساط، پیامک‌ها، برچسب‌ها) به‌هم نخورد.
* **منتقل نمی‌شود:** مخاطبین، بودجه، وام، پس‌انداز، چک و تراکنش‌های تکرارشونده‌ی نیوو (در فایل‌هایی که بررسی شد خالی یا بی‌ارتباط با تراکنش‌ها بودند)، و متن پیامک‌های بانکی.
* واحد پول پیش‌فرض بدون تبدیل است (تومان به تومان). اگر پارمیس شما ریالی است: `--amount-multiplier 10`.

## نسخه‌های تست‌شده

* پارمیس اندروید ۵٫۷٫۹۸٫۲ (دیتابیس نسخه‌ی ۱۲ و ۱۳)
* پشتیبان نیوو با دیتابیس نسخه‌ی ۱۸

برای نسخه‌های دیگر ابزار هشدار می‌دهد. اگر با نسخه‌ای کار کرد/نکرد، Issue بازکنید (بدون پیوست کردن فایل شخصی).
